One tool call = one completed command_execution or file_change item in the agent's Codex trajectory log; the expanded list shows each command's category and its shell exit (✓ ok / ✗ non-zero). Categories are assigned by keyword: read (cat/sed/objdump…), search (rg/grep/find), build (make/clang…), run (the fuzz target, PoC), edit (patch/file edits), test, shell. Outcome is the two-authority verdict; pass@1 counts verified successes in the counted trial.
